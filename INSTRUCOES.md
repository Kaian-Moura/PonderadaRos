# Instruções para Rodar o Dog Draw no Turtlesim

Este projeto desenha um Bulldog Francês no Turtlesim usando ROS 2.

## Pré-requisitos
- ROS 2 instalado (Humble, Foxy, etc.)
- Turtlesim instalado

## Como Executar

### 1. Abrir o Turtlesim
Em um terminal, execute:
```bash
ros2 run turtlesim turtlesim_node
```

### 2. Preparar e Rodar o Desenho
Em **outro terminal**, navegue até a pasta do projeto e execute o script de setup:

```bash
chmod +x setup.sh
./setup.sh
```
